# Changelog

All notable changes to `ste-compiler` are documented here. The project follows Semantic
Versioning. Until 1.0, minor releases can contain documented breaking changes.

## [Unreleased]

### Added

- Reproducible training foundations for strict architecture-specific configurations and immutable
  dataset release verification.
- A source-grounded causal-relation IR, deterministic realization, and semantic validation path.
- A reproducible, MIT-licensed demonstration corpus with frozen splits and checksummed artifacts.
- A credential-free raw-source-to-validated-text reference workflow.

## [0.1.0] - Unreleased

### Added

- Typed semantic IR, deterministic controlled-English realization, and independent validators.
- Constrained symbolic generation boundaries for encoder-decoder and decoder-only LoRA models.
- Vocabulary and terminology registries, symbolic training-record export, evaluation reports, and
  command-line tools.
